# V3 backtest: 2026-11-04

[GitHub Actions run](https://github.com/Giovannicosta/Stock-Market-ML/actions/runs/41817861085)

Data: Yahoo Finance via yfinance, daily adjusted OHLCV from 2000 onward. Nine surviving US stocks and SPY. The V3 portfolio model chooses among stocks weekly (5 trading sessions) or uses SPY as a fallback. Costs: 10 basis points **per transaction side**; comparison also charges SPY initial/final turnover.

## Replication across different data downloads (important)

**This result is NOT currently stable.** Three executions of the same V3 source and nominal date range obtained meaningfully different returns after independent historical Yahoo Finance downloads:

| GitHub Actions run | V3 historical cumulative return | SPY cumulative return | Selected validation gate |
| --- | ---: | ---: | --- |
| [41817861085](https://github.com/Giovannicosta/Stock-Market-ML/actions/runs/41817861085) | +178.95% | +85.43% | 0.10% threshold, disagreement penalty 0.5 |
| [41818183806](https://github.com/Giovannicosta/Stock-Market-ML/actions/runs/41818183806) | +247.06% | +85.43% | 0.10% threshold, disagreement penalty 0.5 |
| [41818222196](https://github.com/Giovannicosta/Stock-Market-ML/actions/runs/41818222196) | +86.91% | +85.43% | 0.00% threshold, disagreement penalty 1.0 |

The V3 **same-file deterministic replay passed** in run 41818222196, so its output is repeatable when the input CSVs are exactly fixed. However, SHA-256 fingerprints for several new Yahoo Finance CSV downloads differed, despite the same requested dates. The source of those changes and the magnitude of price revisions have **not been diagnosed**. The V2 model also varied greatly on independent downloads: historical model returns of -19.15%, +29.74%, +4.67%, and -10.35% were seen across its runs.

**Therefore: a high backtest return is not sufficient evidence that V3 has a durable forecasting advantage. Do not use it for trading.** Freeze dataset snapshots off Git (subject to vendor terms), diff revised quotes, run data-integrity and stability checks, and validate forward in paper trading before proposing any real orders.

## First-run historical illustration (retrospective)

Last 20% of available weekly signal dates: **2021-08-10 through 2026-10-21** (262 periods).

| Measure | V3 weekly model | SPY |
| --- | ---: | ---: |
| Total compounded return | **+178.95%** | +85.43% |
| Annualized return | +21.82% | +12.61% |
| Sharpe, risk-free = 0 | 0.901 | 0.858 |
| Max drawdown | **-40.41%** | -23.93% |

V3 exceeded SPY by historical return, **but its drawdown was substantially larger**. Model mean absolute error on excess returns was 0.0262631 versus 0.0262547 for predicting zero excess, indicating **no improvement in absolute forecasting error** over the naive baseline.

Selected using *development folds only*: stock rotation mode; forecasted excess threshold **0.10%** per five-session period, ensemble-disagreement penalty **0.5**. The model allocated to one or more stocks in **95.42%** of weekly periods. Its total one-sided turnover measure was **309.93** over the holdout (sum of absolute portfolio allocation changes, including initial and final liquidation).

## Reproducibility concern

The replication table above documents substantial cross-download variation. SHA-256 hashes and same-file rerun checks are now built into the workflow. The problem remains unresolved; no real-money deployment is warranted.

## Key scientific limitations

- V2 already examined approximately this same 2021–2026 historical period. Therefore V3's final slice is **not truly new, prospective evidence** for the overall project; design decisions may already reflect what we learned about that period.
- The ticker universe is composed of present-day survivors; delisted stocks and historically changing index membership are absent (**survivorship bias**).
- The strategy's strong returns may reflect concentration in high-growth stocks rather than repeatable short-horizon forecasting skill; ticker attribution should be added.
- Split- and dividend-adjusted opening prices are not executable market quotes. Slippage, variable spreads, taxes, liquidity constraints and broker order handling are not modeled.
- The ensemble disagreement gate is an uncertainty *heuristic*, not a calibrated confidence interval.
- **Do not execute real-money buys/sells** based on this historical result. Next meaningful test is logged paper trading on fresh future dates, with code/model parameters frozen.
